# Gnanadhara Foundation NGO Web Development



---

## 📋 Project Overview

### Mini Project 1: AI Agents & Automation Workshop Registration Form

This project implements a **registration form** for the **AI Agents & Automation Workshop**. The form collects participant information and validates their eligibility for the workshop.

---

## ✨ Features

### Form Fields Included:

1. **Personal Information**
   - Name (Text field - Required)
   - Email (Email field - Required)
   - College/Organization (Text field - Required)

2. **Skill Assessment**
   - AI Skill Level (Radio buttons)
     - Advanced
     - Intermediate
     - Beginner

3. **Workshop Requirements**
   - Laptop Availability (Radio buttons)
     - Yes
     - No
   
4. **Session Scheduling**
   - Preferred Session Timings (Dropdown)
     - 10:00 AM - 12:00 PM
     - 2:00 PM - 4:00 PM
     - 6:00 PM - 8:00 PM

5. **Payment Verification**
   - Upload Payment Screenshot (File upload - Required)

## 📝 How It Works

1. Users fill out the registration form with their details
2. Required fields must be completed before submission
3. Upon clicking Submit button, JavaScript displays a success message
4. Users can reset the form using the Reset button

---

## ✅ Form Validation Features

- All fields are marked as **required** (HTML5 validation)
- Email field validates for proper email format
- Radio buttons ensure single selection for skill level and laptop availability
- File upload is required for payment verification
